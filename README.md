# Customer Sales Data Analytics

## Project Overview

This project demonstrates the application of basic data analytics techniques to a sample customer sales dataset. The project focuses on data preparation, exploratory analysis, data visualization, and linear regression.

The project was created as a portfolio demonstration of concepts and skills developed through coursework in data analytics.

## Objectives

The objectives of this project are to:

* Prepare and inspect a business dataset.
* Identify missing or incomplete data.
* Calculate descriptive statistics.
* Analyze revenue by product category and geographic region.
* Visualize business trends.
* Apply linear regression to examine the relationship between advertising spending and revenue.
* Interpret analytical results from a business perspective.

## Dataset

The dataset contains 20 sample customer sales records.

Variables include:

* Customer ID
* Customer age
* Region
* Product category
* Units sold
* Unit price
* Advertising spend
* Revenue

The dataset is fictional and is intended for educational purposes.

## Analysis Performed

### 1. Data Preparation

The dataset was loaded into Python using Pandas. The analysis included reviewing the dataset structure, descriptive statistics, and missing values.

### 2. Revenue Analysis

Revenue was grouped by:

* Product category
* Region

This was used to identify which categories and regions generated the most revenue.

### 3. Data Visualization

Bar charts were created to visualize:

* Revenue by product category
* Revenue by region

### 4. Linear Regression

A linear regression model was developed to examine the relationship between advertising spending and revenue.

The model uses:

**Advertising Spend → Revenue**

The regression results can be used to evaluate whether higher advertising spending is associated with higher revenue within the sample dataset.
